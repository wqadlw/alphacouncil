## 0. ⭐ 本文件为什么存在：不是"没有规范"，是**规范没被实现**

2026-09-28 复核时的事实：

| 规范要求 | 实际实现 |
|---|---|
| **12 个核心组件**（`前端资源与打磨规格` §4.3） | **0 个**。`Page` / `PageSkeleton` / `EmptyState` 是 spec 022 临时补的，不在那张表里 |
| **⌘K 全局搜索面板**（§七） | **未实现**。全站零搜索 |
| **Lucide / Tabler 图标**（§3，已定） | **零图标** |
| **DataTable**（决策日志 / 卡片列表） | **未实现**。决策与卡片是卡片堆，不是表 |
| **圆角 > 4px 禁止**（§4.4） | 遵守（我们本来就基本没圆角） |
| **任何 `box-shadow` 禁止**（§4.4） | 遵守（`index.css` 全局 `box-shadow: none`） |
| 正文 12px / 11px（91 次 / 7 次） | ⚠️ **字号分配没有规则**，于是全用小字 |

**所以这份文件的实质是：把一份已经很细的规范，变成能照着写的实现约定。**

### 0.1 与姊妹项目那份「Industrial AI Clean」的冲突裁定

`D:\AAA\b2b-rfq-copilot\docs\FRONTEND_STYLE_GUIDE.md`（同主人的另一项目，v1.0，ADR-008）
是一份**同样认真**的应用规范，但**它在几处与本项目的规范是有意不同的**：

| | AlphaCouncil | Industrial AI Clean | 裁定 |
|---|---|---|---|
| 圆角 | **> 4px 一律禁止** | 8 / 12 / 16px | **采纳本项目**。理由写在 §4.4：「一圆就变成 SaaS 后台，不是研报」 |
| 阴影 | **任何 `box-shadow` 禁止**（研报是印刷品） | `0 1px 2px` | **采纳本项目**，**但开一个例外**：⌘K 浮层是**离开文档平面**的唯一元素，允许一层极淡的遮罩（§3.2） |
| 衬线 | **必须**用于标题与主张 | 全 Inter，无衬线 | **采纳本项目**，并**明确分工**：衬线=内容（主张、原话、象限判语），无衬线=外壳（导航、表格、标签） |
| 入场动画 | **禁止**（每次打开都等 = 像 Landing Page） | `fade-slide` 0.18s | ⚠️ **2026-09-30 起本行被 ADR-0033 推翻**，且**只对开屏成立** —— 见下面的逐条说明 |
| 字号 | 11/12px 用于表头与元数据 | 正文 ≥ 13px | ⚠️ **两者都对，因为说的是不同东西** —— 见 §2.2 的裁定 |

> ### ⚠️ 入场动画这一行，2026-09-30 被推翻（ADR-0033）
>
> 原文是「**本产品零入场动画**」，依据是上表第三列的理由：
> 「每次打开都等 = 像 Landing Page」。**这个理由本身是对的，而它被用错了地方。**
>
> 「每次打开都等」说的是**频率**问题：一个每天开二十次的东西，
> 二十次都让人等，是产品的缺陷。而 §7.1 的 L1/L2 分级本来就在管**触发式**动效 ——
> L1 是「你造成的，你看得见」，L2 是「状态转换」。**开屏既不是触发式也不是状态转换**，
> 它是一次性的入场，而 §7.1 没有为它留位置。
>
> 于是 ADR-0033 没有删掉这一行，而是**把它缩小到一个具体的屏幕**：
>
> - **开屏（`StartupPage.tsx`）** —— 一天一次，读者不主动触发，**允许入场动画**，
>   时长落在新设的 **L3 带（600–1600 ms）**，并由 `V-06` 断言每个 `@keyframes`
>   都能被 `prefers-reduced-motion` 关掉。
> - **其余每一个屏幕** —— 仍然是零入场动画。
>
> ⚠️ **L3 这一带被钉死在开屏上**：`styleguide.test.ts` 的
> 「confines the L3 entrance band to the launch screen」要求任何 600–1600 ms 的
> 声明都必须落在一条 `startup-` 选择器里，外加一条「树里至少有一个 L3 时长」
> 免得这条规则守着一个不存在的屏幕。
> **一个谁都能用的带不是带，是许可。**
>
> ⚠️ 上表第三列那句「像 Landing Page」仍然适用于产品内的任何一屏 ——
> 被推翻的是「**零**入场动画」这个**量词**，不是那个判断。

**采纳姊妹项目的**：工程管道（`cn()` / `cva` / 组件清单 / `app/ components/ hooks/ lib/` 分层）
与**「一个 minimal set 就够，不要装重型库」这个判断**。它用 3 个小依赖做到了一个
像样的应用界面，这份可行性证明直接决定了本项目的依赖预算（§6）。

**不采纳的**：圆角、阴影、衬线取舍、动画风格。

## 1. 风格关键词

```text
克制 · 印刷品 · 数据密度 · 可信 · 无装饰 · 静态
```

**禁止**：霓虹渐变 / 玻璃拟态 / 彩色胶囊 / 入场动画 / 数字滚动 / 阴影 / 圆角胶囊。

## 2. 字体与字号

### 2.1 字族

```css
--font-serif: "Songti SC", "SimSun", Georgia, "Times New Roman", serif;  /* 主张与标题 */
--font-sans:  "PingFang SC", "Microsoft YaHei", system-ui, sans-serif;    /* 外壳与数据 */
--font-mono:  "JetBrains Mono", ui-monospace, "SFMono-Regular", monospace; /* 数字与代码 */
```

⭐ **分工是强制的**：**衬线只用于"标题与主张"**（规则 1）。导航、表格、标签、
按钮**一律无衬线**。数字列用 mono + `tabular-nums`（规则 2）。

### 2.2 ⭐ 字号分配（本文件对两份规范冲突的裁定）

分歧的根源是**两边说的不是同一件事**：姊妹项目的「正文 ≥ 13px」是给**散文**的，
本项目的 11/12px 是给**表格铬饰**的。所以不是取平均，是**分工**：

| 用途 | 字号 | 允许 11/12px？ |
|---|---|---|
| 页面标题 | 22 / 30，衬线 | — |
| 卡片/主张/象限判语 | 17–20 / 26，衬线 | — |
| **正文散文**（理由、反面证据、复盘说明） | **13 / 20** | ⛔ **不允许** |
| 表格单元格 | 13 / 18 | — |
| 表格表头 / 元数据 / 计数 | 12 / 16，全大写 `letter-spacing: 0.06em` | ✅ |
| 徽章 | 11 / 14 | ✅ |

> **判据一句话**：**要读成段落的字不得小于 13px；表格与标签可以小，因为它们不是段落。**
> 规则 6（信息密度优先）说的是后者。

### 2.3 数字

- 全部 `font-variant-numeric: tabular-nums`，否则列会跳
- 涨跌**色 + 符号双编码**（规则 3）：**红涨绿跌**，A 股约定
  （`--color-up: #c0392b` / `--color-down: #1e7a46`，**不可与欧美约定互换**）
- 涨跌箭头 **▲▼ 自绘**，与数字同色，**不用图标库的通用箭头**（§3.3）

## 3. 色彩令牌

### 3.1 令牌表

```css
@theme {
  --color-paper:      #fbfaf8;   /* 页面底 */
  --color-paper-soft: #f4f2ee;   /* 次级底 */
  --color-surface:    #ffffff;   /* 浮层/表格头 */
  --color-ink:        #0e1a26;   /* 主文字 */
  --color-ink-soft:   #3a4756;   /* 次文字 */
  --color-ink-faint:  #7a8797;   /* 弱文字 / 禁用 */
  --color-navy:       #1e3a5f;   /* 强调 / 选中 */
  --color-brass:      #9a7b4f;   /* 选中标记 / 警示 */
  --color-rule:       #d9d5cd;   /* hairline */
  --color-rule-soft:  #e8e5df;   /* 更弱的分隔 */
  --color-up:         #c0392b;   /* 涨（A 股：红） */
  --color-down:       #1e7a46;   /* 跌（A 股：绿） */
  --color-warn:       #b4690e;   /* 警示 */
}
```

⭐ **规则 7：颜色只承载意义**（涨跌 / 警示 / 类型），**装饰一律中性**。
所以除 `up` / `down` / `warn` / `navy` / `brass` 外，**不允许出现任何有色**。

### 3.2 阴影与遮罩

**默认零阴影**（规则 4：0.5px hairline 代替阴影；§4.4：研报是印刷品）。
全局已在 `index.css` 强制 `* { box-shadow: none }`。

**唯一例外**：⌘K 命令面板的遮罩 —— 它是**唯一离开文档平面**的元素。
允许 `background: rgb(251 250 248 / 0.2)` 作为**纸白半透遮罩**
（**不是黑色遮罩**），面板本身仍**零阴影、1px `--rule` 边框**。

## 4. 形状

| 用途 | 圆角 | 说明 |
|---|---|---|
| 按钮 / 输入框 | **2px** | |
| 卡片 / 浮层 / 面板 | **4px** | 上限 |
| 徽章 / 标签 | **2px** | ⛔ **禁止胶囊**（`rounded-full`） |
| 表格 / 列表行 | **0** | |

⭐ **超过 4px 一律视为缺陷**（§4.4）。

## 5. 图标

- **唯一主库 Lucide**（§3.1 已定，ISC）
- `stroke-width` 三档：`icon-sm` 1.5（<14px）/ `icon-md` 1.25（16–20px，默认）/ `icon-lg` 1（≥24px）
- 只用 `currentColor`，不写死颜色（⭐ **颜色只承载意义**，图标不该抢注意力）
- **⛔ 禁止 emoji 作功能图标**
- 自绘金融图标（§3.3）：三表 / 估值 / 决策 / 复盘 / 知识 / 涨跌 ▲▼
  —— 24×24 画布、`stroke-width: 1.5`、圆角线帽、**只此一份 SVG sprite**（§7）

## 6. 依赖预算（宪法第三条：未经明确批准禁止新增）

**2026-09-28 主人批准，且只批准这四个**（与姊妹项目的实际依赖集一致）：

```text
lucide-react · class-variance-authority · clsx · tailwind-merge
```

**明确不装**：shadcn/ui 全量（Radix 一整套）· TanStack Query / Router · Zustand ·
React Hook Form + Zod · Recharts · auto-animate / motion / GSAP · 图表库 ·
自托管字体包。

⭐ **为什么这个预算够**：`前端资源与打磨规格` §4.1 说坚持 shadcn/ui 是因为
「**复制源码进仓库 + 没有运行时依赖**」—— 而 shadcn 的模式**就是**用
`cva` + `clsx` + `tailwind-merge` 手写组件。**我们手写，用同样的三个工具，
但不引入 Radix。** 需要无障碍的浮层时手写焦点陷阱与 `aria-*`。

## 7. 动效

### 7.1 分级（§5.2）

| 级别 | 时长 | 用途 |
|---|---|---|
| **L0 · 无** | 0 | **数据本身** —— 表格数字、图表、卡片内容**永不跳动** |
| **L1 · 微反馈** | 100–120ms | hover 底色 / focus 环 / 按下 |
| **L2 · 状态过渡** | 180–220ms | Drawer 滑入 / 面板展开 |
| **L3 · 一次性入场** ⭐ | 600–1600ms | **仅开屏**，2026-09-30 由 ADR-0033 新增。L1/L2 描述的都是**读者触发的状态变化**，而开屏既非触发也非转换；220 ms 的上限会把一幅 1200 ms 的立轴变成一次抽搐，那不是入场动画，那是加了礼貌的闪屏 |

缓动统一 `cubic-bezier(0.2, 0, 0.2, 1)`。

> ⭐ **L3 的上限才是重点。** 过了大约 1.6 s，入场就不再是入场而是**等待**；
> 而在进入产品的路上让人等，是这个产品唯一不能做的事。下限同理：
> 短于 600 ms 就没有「落定」可言，那个效果只有量它的人能察觉。

### 7.2 ⭐ 六条禁令（§5.3）

入场动画（stagger / fade-in-up）· 骨架屏 shimmer · **数字滚动 count-up** ·
弹跳/过冲 · 视差/粒子 · 图表入场。

> ⭐ **数字滚动是最危险的一条**：把"看数据"变成"看表演"，**且暗示收益**。
>
> **一句话：动效只用来"说明状态变了"，不用来"吸引注意"。**

> ### ⚠️ 2026-09-30 · 第一条被推翻，其余五条全部保留（ADR-0033）
>
> 上面那句「一句话」本身仍然是本节的判准，**而它恰好就是第一条禁令未被推翻的原因** ——
> 开屏不是「用来吸引注意」的，它是**这个产品是什么**。所以第一条被缩小到**开屏一个屏幕**
> （见 §7.1 的 L3 与文首那张表的逐条说明），而不是被删掉。
>
> **保留的五条，各自有牙齿：**
>
> | 禁令 | 谁在强制 |
> |---|---|
> | 骨架屏 shimmer | 未实现；一旦实现，`V-06` 会要求它能被 `prefers-reduced-motion` 关掉 |
> | **数字滚动 count-up** | `V-06` 第二条断言：样式表里任何作用在**含数据词的类名**上的 `animation` 即失败。分词在连字符处切开，所以 `.ticker-price` 会被抓而 `.disclose` 不会 |
> | 弹跳 / 过冲 | 未实现；缓动只有 `cubic-bezier(0.2, 0, 0.2, 1)` 一种，无回弹 |
> | 视差 / 粒子 | 未实现 |
> | 图表入场 | 同「数据本身永不跳动」：§7.1 的 L0 是**这一整节唯一被完全保留的禁令**，且它是关于产品含义而不是装饰的 |
>
> ⚠️ **注意 count-up 那条是被机械强制的**，不是靠自觉：写一个
> `@keyframes` 给价格加动画会让 `V-06` 变红，而这条断言的第一版匹配的是 JSX 里的
> `animate-*` —— 两处都不对：它只看得到 Tailwind 类名，看不到真正让东西动起来的
> `animation` 声明，而且会对一个写了却没用上的类名报警。

### 7.3 骨架屏

**静态灰块，禁止 shimmer**（规则 7 + §五）。形状要贴近真实内容的高度，
否则内容落位时会跳。

## 8. 组件清单

### 8.1 底座（手写，cva 变体）

`Button` · `Input` · `Textarea` · `Badge` · `Card` · `Rule`（hairline）· `Skeleton` · `EmptyState`

### 8.2 数据与导航（本项目特有）

| 组件 | 关键规格 |
|---|---|
| `DataTable` | 0.5px 全表线 · 表头全大写 12px · **数字右对齐 + tabular-nums** · 行高 32/40 · 排序箭头 1px |
| `CommandPalette` | ⌘K / Ctrl+K · 墨蓝浮层 + 1px 边框 · 分组标题全大写 11px · **选中项左侧 2px 金线**（不是整行高亮） |
| `Sidebar` | 分区 + 搜索框常驻；计数用 `ink-faint` |
| `DetailPane` | 右侧详情；⛔ 不用全屏黑遮罩 |
| `BacklinkList` | 「被这些记录引用」—— 知识库像知识库的地方 |
| `RecordTimeline` | 渲染 append-only 事件（`card_events` / `reviews` / `decisions`） |

### 8.3 ⭐ 空状态（规则 8）

**一句事实陈述 + 一个动作。禁止插画、禁止 emoji、禁止「还没有...」式的占位套话。**
反例：「🎉 还没有卡片」；正例：「没有卡片。有出处的判断才值得记。」

## 9. 目录结构（采纳姊妹项目）
