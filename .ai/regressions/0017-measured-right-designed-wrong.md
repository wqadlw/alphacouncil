# 0017 · 「量出来是对的」与「设计是对的」是两件事，而这一次量对了做错了

- **发现日期**：2026-10-01
- **严重级别**：P3（**记录它是因为它最容易被误当成成功**，产品无损坏）
- **状态**：已回退，理由写在样式表里

## 现象

开屏重做到第五版。左栏与画框各自居中，于是**两边都没对齐**：日期行在画框顶边
下方 207px，署名在画框底边上方 178px。

量出来：

```
frame   top 130  bottom 741   (611 tall)
copy    top 337  bottom 563   (226 tall)
```

这不是「细节不完美」，是**两半各自居中所以互不呼应**。

## 试法：让左栏撑满并两端对齐

```css
@media (min-width: 1180px) {
  .startup-copy {
    align-self: stretch;
    justify-content: space-between;
  }
}
```

栅格行本来就等于较高那一列的高度，所以**不需要任何新数字** —— 日期落在画框顶边、
署名落在底边，中间是那句话与出口。测出来的意图是实现了的。

## ⭐ 而它更糟

```
copy column   480 x 796   （原 480 x 226）
洞            60..280、350..567、600..816   —— 三个，每个约 200px
```

**四行字铺在 796px 上，是四个碎片，不是一个陈述。**

上面那个「居中的文字块上方的空白」是呼吸，读起来是沉着；**同样高度里填三个洞**，
读起来像一页加载失败的东西。

⇒ 已回退到居中，并把这三点写进样式表 `.startup-signoff` 上方。

## ⭐ 这一条值得单独记，因为它最容易被误当成成功

- 测量**成功**了：两个边缘确实对齐了，数字可以对上。
- 设计**失败**了：空间分配把一个陈述拆成了四个碎片。

**「我量了，所以我对」是把测量当成了验收。** 本仓已记录的 0016 是同一个硬币的
反面 —— 那次测量**没做**，所以缺陷藏住了；这次测量**做了**，所以缺陷才被发现。

⭐ 差别在于：0016 需要的是**多测一个尺寸**，0017 需要的是**测完之后再看一眼结果长
什么样子**。数字正确和视觉正确是两个断言，而截图只花几秒。

⇒ 已做：截图自查这一步在本轮至少做了四次，每次都推翻了一个「数字正确」的方案
（画框装裱过度、画被压小、空洞三个）。⇒ 已记：`.ai/failure-modes.md` 新增一条
「量过的方案仍然要看一眼」。

## 回归测试

**没有，也不该有。** 这不是一条可断言的不变量 ——「四行字不该铺成 796px 高」是审美
判断，不是规格。硬把它写成断言会得到一条谁都不敢改的门禁。

⚠️ 但有一条**可以**固化的、且不是审美：左栏与画框的**中心**应相差不超过若干像素。

```
两栏中心相差 14px（文字 337..563，中心 450；画框 130..741，中心 436）
14px 的来源是 wall 列的高度含了画框下方的署名行
14px / 900px = 0.7%
```

⇒ **明确记为「不追」**：0.7% 没有读者的眼睛会去配对，为它写一个数字会让这个文件
开始积累假精度。此判断写进样式表注释，与回退理由放在一起 —— 因为**回退的理由和
留下的理由一样都需要被记下来**，否则三年后的人会以为那是随手写的。

## 是否可被测试固化？

❌ **不能。** 理由写在上节：这是审美判断，写成断言就是一条假门禁。
