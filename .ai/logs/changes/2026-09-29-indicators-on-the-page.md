# 2026-09-29 · 指标上屏，以及一个测试全绿的真缺陷（spec 038）

> 起因：主人说「继续你决定」。`spec 037` 把指标算出来了，**34 条测试守着，一个数字都没上屏**。
> 执行：OpenCode（Codex）· 模型：Space Bunny Free

## 一、本篇只做一件事

把已经算好的东西画出来，⭐ **并且不引入第二份算法**。

前端当然可以写一个 `sma()`。那会得到第二个实现，而它和 Python 那份从第一根起
就可能不同，⭐ 直到有人改了一边才暴露，暴露的时候**没有测试会红，因为两边都「对」**。

`spec 037` 把六个口径分叉逐条钉死，就是为了**只有一处**能改。
再加一份 TypeScript 等于把那份文档变成两份互相矛盾的文档。

所以 `DailyResult.value` 从 `DailyBar[]` 变成 `{ bars, indicators }`，
⭐ 且 **`values` 与 `bars` 等长同序**，预热段是 `null` 而不是「跳过」。

少一格就得让前端去猜某个值属于哪一根 —— ⭐ 而每一次这样的猜测都是一个可能错一格的地方，
**错一格的线在图上看不出来，只在有人拿已知值核对时才发现。**

## 二、⭐ 4.2.0 没有分 pane，所以 MACD 是第二张图

不凭记忆，数 typings：

| 符号 | 出现次数 |
|---|---|
| `paneIndex` | **0** |
| `addPane` | **0** |
| `addSeries` | **0**（那是 v5） |
| `addLineSeries` | 6 |

两条捷径都不可接受：叠在价格轴上，±8 的 MACD 在 300 的价格里是一条平线；
给它一根覆盖价格轴，读者会把第二个数字当成第二个价格。

所以是**独立的第二个 chart 实例**，两张图互相喂 `setVisibleLogicalRange`。

⭐ 而这**不是装饰**：蜡烛从第 0 根开始，`dif`/`dea`/`histogram` 在预热段是 `null`，
**两张图默认的可视区间根本不一样** —— 面板会晚 33 根打开，
两张图会对「光标底下是哪一天」各说各话。

守卫标志不是可选项：`setVisibleLogicalRange` 会重新触发对方的 handler。

## 三、⭐ 图例只列画出来的东西，而这是渲染出来才看见的错

第一版有 `SERIES_COLOR` 表 + 两份并行 id 数组 + 一个 `?? FALLBACK`。

错在：**名字不在数组里的指标，会从图上丢掉，却仍然出现在图例里**，
因为图例渲染的是 `indicators` 而不是「画了的那些」。
⭐ 结果是图上有一条写着「RSI」的图例项，而底下没有线 ——
**一条图上不支持的断言，而它每一部分单看都是真的，所以活得下来。**

`FALLBACK` 从来不是答案；`FALLBACK` 只是在掩盖「丢弃是个必须告诉人的决定」。

改法是一张 `PLACED` 表（颜色和窗格住在一起，忘记窗格不再可表达），
丢掉的一律进 `unplaced`，⭐ **页面上写出来**：「服务端算了 5 条，本页只画 5 条；未画的是 …」。
沉默不在选项里。

## 四、⭐ 颜色：四个标签只有两种颜色，浏览器里才看得见

截图才看见的：**MA20 和 DIF 同为藏青，EMA12 和 DEA 同为黄铜**。
图例一行四个标签两种颜色，⭐ **读者没法靠颜色区分两条线 —— 读者读图例是横着读的。**

指标面板这一对刻意**不占用红绿**：那两色在这个项目里意味着涨和跌，
花在震荡指标上会让页面在意思是「正」的地方说「涨」。

同一次截图还修掉一个更早的：MACD 柱的图例色块原本是**单一红色**，
而图上那个柱是**一半红一半绿**。⭐ 单一色块会命名一个图上从不画出的记号。

## 五、⭐ 顺手修掉一个 34 条测试全绿的真缺陷

浏览器实测数非空值时发现的：

```
dif  warmup=25
dea  warmup=25      ← docstring 说该是 33
```

`ema` 用**前 period 个值的 SMA** 播种，`macd` 里手写的 DEA 用**第一个值**播种。
⭐ 于是**同一份文件里有两个 EMA 定义，逐根不同，而文档描述的是第三个。**

`macd()` 的 docstring 说「DEA 继承 `ema` 的播种，所以多 `signal - 1` 个 `None`」。

修法就一句 —— `dea` 变成对 `ema` 的**调用**，文件里 EMA 的定义从 2 个变成 1 个。

**为什么 34 条测试没抓到**：`TestMaturityIsTheConstitution` 的参数化表逐条钉死每个指标的
预热段，而 **`dea` 不在表里**（`dif` 在）。⭐ 而 `test_no_indicator_ever_invents_a_zero`
里 `dea` **是**在的 —— 一个在场一个不在场，说明写测试时知道 `dea` 归一化不出 33，
于是没往表里放。**表沉默，文档继续说 33，代码继续给 25。**

⭐ **终值一个都没变**（DIF -15.94 / DEA -11.78 / 柱 -4.16）——
182 根的 EMA9 把种子洗掉了。变的只有头部 8 根，
而头部 8 根正是图上「这条线从哪里开始画」的那几根。
**看图看不出来、看末值看不出来、看任何聚合值都看不出来。**

⇒ `regressions/0010` · `failure-modes` F-112

## 八、⭐ 门禁第一次跑出红，是 mypy 不是功能

11 步里 `typecheck` 红了：

```
indicators.py:199: error: Incompatible types in assignment
  (expression has type "list[None]", variable has type "list[float | None]")
```

⭐ `[None] * n` 推断成 `list[None]`，而 `list` 不变，所以拼进 `+` 就是类型错误。
修法是给 pad 一个独立的名字（`pad: list[Indicator] = [None] * ...`），
⭐ **而不是 cast** —— cast 会把一个推断问题藏起来。
