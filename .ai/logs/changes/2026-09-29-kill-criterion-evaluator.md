# 2026-09-29 · 失效条件求值器 —— 让「到期」能变成「触发」（spec 040）

> 起因：主人说「把功能好好看看，再加一些功能，看看 TSP 有什么」。
> 执行：OpenCode（Codex）· 模型：Space Bunny Free

---

## 一、⭐ 先撤回我上一轮的一个判断

上一轮我把 TSP 的「监控中心」「异动监控」归进**不做**，理由是「做了就不是 AlphaCouncil 了」。

⭐ **那个理由没有依据。** `references/research/2026-09-29-tsp-capability-matrix.md` 是一份
**数据层**矩阵（`Dataset` / 能力声明 / 路由 / 源可用性），
**它从来没有走过 `docs/features.md` 的功能清单**。
用一份数据层矩阵去否掉一整个功能面，是拿一张不相关的地图说「那边没有路」。

而项目自己的 `status.md` 里有**两行**写着同一个缺口：

> **J3** … **还差**：复盘页的导航入口 · **主动触达**（受红线 8 约束，
> 形态应是今日页上的一行陈述而非通知，**需单独 spec**）
> **J5** … 还差：变异检查本轮未跑；「转卡」的界面没有

⭐ **「主动触达」被项目自己记了两次，而我判它「不该做」。** 本篇就是那个 spec。

## 二、⭐ 缺口长什么样，以及一句现在为假的话

`/api/v1/today` 的全部求值逻辑（改前）：

```python
for row in decision_repository.list_all(connection):
    for criterion in row.kill_criteria:
        if criterion.due(as_of=today_date):      # ⭐ 只有日期
```

**它只问「到期了吗」。从不问「越过阈值了吗」。**
而 `DueCriterionRead` **已经把 `metric` / `operator` / `threshold` 传到了前端** ——
前端拿得到判据，**只是没有值可以比**。

今日页因此印着一行（第 95 行）：

> 到期不等于触发：**系统还没有指标数据源**，能不能成立要你自己看一眼。

⭐ **这句话现在是假的。** spec 034 给了 HTTP 出口，spec 037 算了指标，spec 038 把它画了出来。
而它之所以成为假话，是因为**它在为一个可以修的缺口拿技术债当借口**：
真正缺的不是「指标数据源」，是「**一个把 metric 名字变成当前值的求值器**」。

⭐ **说错原因比不说更糟** —— 读者会以为那是一件很大的、大到做不了的事。

## 三、⭐ 目录的入选门槛只有一条

`KillCriterion.metric` 是**自由 token**，只做形状校验，docstring 写着
「指标目录属于财务数据层（D4），而它没建；在这里编一份清单，
意味着 D4 落地那天会拒绝一个有效指标」。

⭐ **所以不许把它改成 enum。** 那是把一条为未来留的门焊死。

求值器另有一份**更小的**目录，⭐ **入选门槛**：

> **口径已经在别处被钉死，才进目录。**

于是目录 = spec 037 的指标集 + `Quote` 模型自己定义的价格事实。**零个新的口径分叉。**

### ⭐ 规则当场咬人了：`change_pct` 被剔除

第一稿里有它。写测试时发现 `Quote` **没有 `change_pct` 字段**（它在 `RealtimeQuote` 上），
而那个名字已经被绑定为「vs 昨收」。

「相邻两根的涨跌幅」几乎肯定是那个意思，
⭐ **但「几乎肯定」不是一个定义**，而一条拿未定义指标求值的判据是一条没人能审的判据。

⇒ 剔除，并且**写成一条测试**（`test_change_pct_is_not_in_the_catalogue`），
因为规则只在它咬到人的时候才算存在。

## 四、⭐ 五个状态，其中三个是「我们不知道」

| 读者看到的 | 状态 | 谁在说话 |
|---|---|---|
| MA20 现在 1185.3 —— **已越过** | `crossed` | 比较本身 |
| MA20 现在 1205.0 —— 没有越过 | `not_crossed` | 比较本身 |
| MA60 **还差 48 根**日线才有值 | `warming` | ⭐ **我们** —— 指标还太年轻 |
| `gross_margin` 不在我们能算的指标里 | `undetermined` | ⭐ **我们** —— 目录没这个 |
| 取不到这个代码的日线 | `no_bars` | ⭐ **我们** —— 源没有数据 |

⭐ **最后三行是本篇的全部价值。** 它们今天**共用同一个沉默** ——
一条永远不会被求值的判据，在页面上和「条件没成立」**长得一模一样**。

而这正是宪法 §4.6 存在的原因：
⭐ **一条从不触发的判据不是沉默，它是在替用户说「你写下的条件没有成立」。**

## 五、⭐ 不加通知 —— 这是红线 8，不是我的选择

`status.md` 已把形态定死：「**今日页上的一行陈述而非通知**」。

⭐ 所以本篇**没有**推送、没有徽标、没有声音、没有弹窗、没有邮件。

这不是取舍，⭐ **这就是红线 8**。而一个越过阈值的失效条件
**正是「拦截」的定义本身** —— 用户自己写下的、针对自己记录的条件，到点了就该拦住他。

## 六、⭐ 三个在过程中被实测/变异抓出来的东西

### 1. 截图里看出来的：红色用错了

第一稿给 `crossed` 用 `--color-up`。截图里才看见：**那个 token 在本项目每张图上都意味着「涨」**，
而「你的判据被越过了」是相反的新闻。⭐ 改成 `--color-warn`（琥珀）。

⭐ **两个含义在同一块屏幕上互相打架**，而它在代码里完全看不出来。

### 2. 变异抓出来的：`NO_BARS` 根本没被测过

变异「让 `no_bars` 落到 `not_crossed`」**存活**了。

⭐ 原因不是测试写得不好，是**这个状态在生产里也不可达** ——
路由先判了 bars，然后发 `metric: null`。于是 `evaluate(criterion, [], ...)` 一次都没被调用过。

⭐ 补上测试的理由不是覆盖率，是**`evaluate` 是公开函数，必须是全函数**：
传空序列进去，它欠调用方一个 `no_bars`，不是一个错答案。

### 3. E2E 抓出来的：一个缺失字段让整页白屏

`today-hub.spec.ts` 的 fixture 没有 `metric` 键 → `undefined` → `metric.state` **在渲染中抛异常**
→ **整个今日页变白**。

⭐ **在读者专门打开来看「出了什么事」的那一页上白屏**，是本项目最贵的一种失败。
所以 `undefined` 与 `null` 同等处理，并且**写成测试**。

## 七、⭐ 变异 11 个：10 杀 + 1 个**声明为等价**

| 结果 | 数量 |
|---|---|
| killed | **10** |
| equivalent（**明确声明为什么它等价**） | 1 |
| SURVIVED | **0** |

⭐ 那个等价变异值得说清楚：把 `observed = value if status is OK else None` 改成 `observed = value`，
测试照绿 —— 因为 `warming` 的 `value` 本来就是 `None`，下面的 `is not None` 照样拦得住。

⭐ **这两行是纵深防御，不是同一份东西的两次拷贝。**
「测试分不出它们」是对代码的**正确**结论，不是应该靠删掉一行来掩盖的缺口。
而第一行**真的**被违反时（变异 9）测得住。

## 九、⭐ 本轮仍然没做的，以及为什么

TSP 的功能清单我这次真的读完了（`features.md` 209 行 + 14 个 doc）。**没拿过来的**：

| TSP 的 | 为什么 |
|---|---|
| 选股（18 个策略） | ⭐ **红线 1**：输出的是「哪些票会涨」 |
| 回测（净值/夏普/胜率） | ⭐ **红线 9**：收益率与业绩 |
| 因子平台（IC/IR/FDR） | 它是为选股找因子存在的；⭐ 「不做选股」的前提下它没有下游 |
| 异动监控 / 监控中心 | ⭐ **红线 8** 明确点名「异动提醒」 |
| ETF | 只是一个资产类型，没有它就缺的独立能力 |
| 9 类关键价位 | ⭐ **红线 3**：它以**市场数据**为输入，不是以**记录**为输入 |
| 盘后定时管道 | ⭐ 全市场定时拉取正是招来封 IP 的做法（§4.5） |
| 盘前风向标 / 龙虎榜 / 概念轮动 | 需要 fuyao / ths 数据源，全部未接 |
| 第三方数据接入（Tushare/CSV） | 加第四个数据源要过 §4.5 的封禁风险排序，而 Tushare 要积分 |
| 分钟 K 策略 / 盘中信号 | ⭐ 分钟 K 端到端**至今未通**，根因未定位（见 `5c5f90f`） |

⭐ **所以「加功能」这一轮的真实答案是：加的不是 TSP 的功能，是 TSP 让这个项目暴露出的
一个自家缺口。** 主人要的东西（市场数据）已经在了；
缺的是**让市场数据去回答你自己写下的问题**的那一层。
