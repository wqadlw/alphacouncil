## 背景与目标

把数据层与检索层的能力，编排成一条**可控、可观测、可干预**的研究流程。

关键设计判断：**为什么用图（Graph）而不是链（Chain）？**

- 投研流程存在**条件分支**：不同问题类型走不同的 Agent 组合；
- 存在**回路**：Critic 提出质疑后可能回到 Research 重新研究；
- 需要**人工介入点**：结论不能全自动产出。

这三点都是 Chain 模型无法优雅表达的，因此选择 LangGraph 的状态图模型。

## 用户故事

- 作为用户，我希望提交一个研究问题后，能看到各 Agent 的分析过程，而不是只等一个黑箱结果。
- 作为用户，我希望在最终结论产出前有机会审核并补充意见。
- 作为系统维护者，我希望每个 Agent 的输入输出都被记录，以便排查「为什么给出这个结论」。

## 功能需求

| 编号 | 需求 |
|---|---|
| FR-1 | 定义共享状态（TypedDict），所有 Agent 读写同一状态对象 |
| FR-2 | 实现 Orchestrator：根据问题类型路由到不同 Agent 组合 |
| FR-3 | 实现数据 Agent：调用数据层获取行情与财务 |
| FR-4 | 实现检索 Agent：调用检索层获取文档证据 |
| FR-5 | 实现技术分析 Agent / 基本面 Agent / 舆情 Agent |
| FR-6 | 实现 Research Agent：综合多 Agent 观点，产出带引用的结论 |
| FR-7 | 实现 Risk Agent：识别风险点与不确定性 |
| FR-8 | 实现 Critic Agent：**专门质疑** Research 的结论，找出无证据支撑的论断 |
| FR-9 | 实现 human-in-the-loop 中断点：结论产出后暂停，等待人工确认 |
| FR-10 | 支持失败重试与最大步数限制 |

## 非功能需求

- **成本控制**：单次运行 LLM 成本上限可配置（默认 $0.50），超限中止
- **循环保护**：最大 Agent 步数（默认 25），超出中止并返回已有结果
- **可观测性**：每个节点在 Langfuse 中生成 span，含输入、输出、耗时、token 数
- **可中断**：支持 checkpoint，中断后可从上次状态恢复

## 验收标准

- [ ] AC-1：给定一个研究问题，能跑通完整图并产出结论
- [ ] AC-2：结论中每个论断都关联至少一个检索来源
- [ ] AC-3：Critic 能识别出人为注入的「无证据论断」（构造测试用例验证）
- [ ] AC-4：超出最大步数时正确中止，不进入死循环
- [ ] AC-5：超出成本上限时正确中止，并记录已产生的结果
- [ ] AC-6：human-in-the-loop 中断点能正确暂停并等待输入
- [ ] AC-7：Langfuse 中能看到完整的执行链路
- [ ] AC-8：任一 Agent 失败时，图按预设策略降级或重试，而非整体崩溃

## 明确不做（Out of Scope）

- 自动交易执行（系统明确不接入券商）
- 多用户并发会话管理（P3 为单会话）
- Agent 自我进化的 prompt 优化

## 边界与异常

| 场景 | 期望行为 |
|---|---|
| 检索层完全不可用 | 图终止，返回明确错误而非编造内容 |
| LLM 返回格式错误 | 重试 2 次，仍失败则降级为纯文本输出并标记 |
| Critic 持续提出质疑 | 限制 Critic 最多触发 2 轮重新研究 |
| 人工长时间未确认 | 会话超时，保留 checkpoint 供恢复 |

## 状态设计（草案）

```python
class ResearchState(TypedDict):
    query: str
    intent: str                      # 路由结果
    quotes: list[Quote]
    financials: list[Financial]
    evidence: list[RetrievedDoc]     # 带溯源
    technical_view: str | None
    fundamental_view: str | None
    sentiment_view: str | None
    draft: str | None                # Research 产出
    critique: list[str]              # Critic 质疑
    risk_notes: list[str]
    revision_count: int              # 重新研究次数
    step_count: int                  # 步数（循环保护）
    cost_usd: float                  # 累计成本
    final_report: str | None
```
