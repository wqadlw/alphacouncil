## 一、为什么是这一个功能（量出来的，不是挑出来的）

主人说「增加功能」。**我没有先去想有哪些功能可以加**，而是先量了一件本仓
`status.md` 已经写着、却一直没有被证伪的事：**哪些能力已经存在，而读者够不着。**

`status.md` D1 那一行写着「还差：标的页入口 · 歧义代码（`000xxx`）让用户选市场的
**前端**交互」。这句话挂了很久。⭐ **而它没有被我验成就一直挂着** —— 挂着的缺口
和真实存在的缺口，在这个仓里长得一模一样（这正是 `regressions/0005` 的教训）。

### 1.1 量的过程，以及量错的三次

我写了一个扫描：列出后端全部路由，与前端所有 `/api/v1` 字面量按**路径形状**对拍。
**前四版全错，每一版都会让我去建已经存在的东西：**

| 版本 | 方法 | 报出来 | 错在哪 |
|---|---|---|---|
| 1 | 路由字符串字面匹配 | 26 个孤儿 | 前端写的是 `` `/api/v1/cards/${cardId}/schedule` ``，**没有任何路由是子串** |
| 2 | 同上，`{x}` 归一为 `*` | **0 / 36 可达** | 用了装饰器上的路径，而它是**相对 `APIRouter(prefix=…)` 的**，每条路由都少一段 |
| 3 | 加上 prefix | 12 个孤儿 | 唯一可疑的两个（`review/due`、K 线）**当场就被我自己的眼睛否掉了** |
| 4 | 剥掉查询串 | 11 个孤儿 | `lessons.ts` 的路径**没有前导斜杠**（`'api/v1/lessons'`），整份文件被跳过 |

⚠️ **这三次错必须写下来，因为「我的扫描发现 26 个坏东西」这句话看起来像一份待办，
而没有人会去复核一个长得像工作量的数字。** `status.md` 已经写着「凡『还差什么』要靠
读代码确认」—— 这次是那句话第一次真的被用上。

### 1.2 最后靠读代码定下来的结论

- **36 / 47 路由前端可达**（教训那一组是 `lessons.ts` 里的，扫描看不见它）。
- 真孤儿有三个，其中**只有一个是读者走不通的**：
  `GET /api/v1/instruments/resolve`。

## 二、那个死结长什么样（对着跑起来的服务量的）

```
GET  /api/v1/instruments/resolve?ticker=000001
  -> 200 {"status":"ambiguous","code":"000001","market":null,
          "display":null,"candidates":["sh","sz"]}

GET  /api/v1/instruments/resolve?ticker=600519
  -> 200 {"status":"resolved","market":"sh","display":"600519.SH",...}

POST /api/v1/watchlist  {"ticker":"000001","reason":"..."}
  -> 400 {"code":"DATA_SOURCE_TICKER_AMBIGUOUS",
          "message":"000001 exists on sh / sz — choose one"}
```

前端 `PoolPage.tsx:107` 是 `addToWatchlist(ticker.trim(), reason.trim())` ——
**第三个参数 `market` 没传**，第 114 行把 `ApiError.message` 原样显示出来。

⇒ **读者输入 `000001`，看到一行英文报错，说「choose one」，而界面上没有任何东西可选。**

三件事同时成立：**死结 · 英文 · 在中文产品上。** 而后端**已经把候选答案算好了**
（`candidates: ["sh","sz"]`），`addToWatchlist` 的 `market` 参数**也已经存在**。
缺的只有「问一次，然后把答案交回去」这一步。

⚠️ **`000001` 不是边角情况。** `api.ts:671` 自己的注释写着「a code like `000001` is
*both* the Shanghai Composite and Ping An Bank」。这是中国代码里最常见的一类歧义。

## 三、设计，以及每一条的理由

### 3.1 先问，再写（而不是写失败了再问）

顺序是 **resolve →（若歧义）读者选 → POST 带上 market**。

**为什么不保留「先 POST，收到 400 再问」**：

| | 先 POST 再问 | 先 resolve 再 POST |
|---|---|---|
| 读者看到 | 一行英文报错，再一次交互 | 一次交互 |
| 写入的记录 | `market` 为空的那次**失败**请求不算记录，所以无害 | 直接带正确的 market |
| 请求数 | 2（1 失败） | 2（成功路径） |
| 理由是否要重打 | **要** —— 表单里理由已经填了，重来一次读者会烦 | 不要，理由原地保留 |

⭐ **最后一行是决定性的。** 关注理由是必填的、而且半年后要面对的那句话（页面自己
这么写的）。**让读者为了选一个市场而重打一遍理由，是拿产品里最贵的一栏去换一个
本来可以避免的错误。** 而「先问」没有任何代价 —— 成功的路径也是两次请求。

### 3.2 ⭐ 候选只给市场，不给名字 —— 而且必须说出来

**`InstrumentDetailRead.name` 对每一个标的都是 `None`**（实测 `sh/000001`、
`sz/000001`、`sh/600519` 三个全是 `None`）。**这个产品没有任何名称数据。**

所以选择器只能说「上海」和「深圳」，**而这对 `000001` 完全没有帮助** ——
上证指数和平安银行都在这两个市场里，读者要选的恰恰是「哪一个」。

**三条推论，全部落在文案上：**

1. **不许猜。** 「你要的是哪一个？」后面接两个没有信息量的按钮，等于让读者猜我们的
   数据缺失。⇒ 撞**红线 13**（不讨好用户）与**红线 15**（Agent 只做抽取与核算，
   不做判断生成）—— 猜「你想的是平安银行」正是那个被禁止的判断。
2. **必须说出我们不知道。** 选择器上方一句话明说：
   **`000001` 在两个市场都存在，而这个产品没有名称数据，所以它不能替你选。**
   一个不解释的歧义提示，读者会以为是产品坏了。
3. **不引入名称数据。** 要有名字就得接一个代码段→名称的数据源，那是 `spec 043`
   那一档的工程量和一个新的失败模式（名字错了比没有名字更坏 —— 它会被当成事实）。
   ⇒ 记为 `status.md` 的一条欠账，**不在本 spec 里顺手做**。

### 3.3 「已经解析出来了」也要说出来

`status: "resolved"` 时，`display` 是 `600519.SH`。把它显示在表单里，
理由是**让读者在写入之前看见我们理解的是哪一个标的** —— 这一行是「记录之前你有机会
发现自己填错了」的那道栏，而本产品其余地方**没有**这道栏。

⚠️ **不自动提交。** resolve 成功也不代替读者按按钮：多一次点击换「写入的东西是我要的」。

### 3.4 解析不出来的那一句原样显示

`DATA_SOURCE_TICKER_INVALID` 的 message 是英文（`'zzz' is not a six-digit code`）。
**本 spec 不翻译它。** 理由：那是数据层对「这不是一个代码」的判断，翻译它就得在
前端维护一张错误码→中文的表，**而那张表会和 `api/errors.py` 的真源漂移** ——
这是本仓已经记过的形状（`S-05` 保证文档 ↔ 枚举 ↔ 代码三方一致，前端那一份没有
这个保证）。⚠️ 记为欠账，不在本 spec 里做。

## 五、明确不做

- **不改后端。** `/instruments/resolve` 与 `POST /watchlist {market}` **都已存在** ——
  这个 spec 只补中间那一块。
- **不加依赖。** `V-07` 清单不变。
- **不做「最近添加」/ 代码补全。** 那是新功能，本 spec 的范围是**把已有的死结接通**。
- **不给标的名。** 见 §3.2。
- **不翻译数据层错误。** 见 §3.4。

## 六、这一轮我自己犯的错（写在 spec 里而不是日志里）

打到了 `%LOCALAPPDATA%\AlphaCouncil\alphacouncil.db`，理由栏写着「探针」。
`ALPHACOUNCIL_DATABASE_PATH` 就是为了防这个，**而我没设**。

`watchlist_current` 复查只剩主人自己那一行（600036）。只增不改的日志里留下
event 15（加入）与 16（不再关注）两条，理由写着「探针写入，不是读者的记录」——
**那是唯一诚实的形状：删掉它们就是篡改历史。**

⇒ 已记为 `failure-modes.md` 的 F-196。**规则：任何写操作探针必须带
`ALPHACOUNCIL_DATABASE_PATH`，包括只读探针所在的同一个脚本。**
