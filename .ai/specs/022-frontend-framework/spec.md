# Spec 022 · 前端框架层（应用外壳 · 统一数据层 · 集中路由）

- **状态**：Active
- **目标阶段**：前端（**不是新功能，是把已有功能装进一个壳**）
- **依据**：宪法第三条（技术栈锁定）· `项目总纲` §2.1⑤（**无推送、无红点、无催促词**）· 红线 8 / 11

---

## 一、为什么现在做这件事

不是"想重构"，是**上一轮暴露的一个结构问题**：

> 复盘页"没有入口"——**不是那一页的 bug，是整个前端没有外壳**。

实测（2026-09-28）：`src/*.tsx` 里**没有任何 `<nav>`**，六个页面各自 import 一个
`HREF` 常量、各自手写一个"← 回到 X"。**全站唯一能到达任何页面的方式是手敲 hash。**

对一个宣称"打开就落在今日页"、且"第 ④⑤ 个时刻用户不会主动来"的产品，
**没有全局导航**是第一位的功能缺失。

---

## 二、⭐ 依赖：零新增（**用户明确批准**）

宪法第三条：

> **未经明确批准，禁止引入新的运行时依赖。**

锁定表的前端一行是 **Vite + React + TypeScript + shadcn/ui**，并明确**不用 Next.js**。
而 **TanStack Router / TanStack Query 不在锁定表里**。

2026-09-28 主人明确选择：**不引入，用现有栈建好框架层。**

> 因此本片**不动** `package.json` 的 `dependencies`。
> `shadcn/ui` 与 TanStack 一样属于"**已采纳、未落地**"——按宪法 §3.0 的纪律，
> **如实标出，不假装已实现，也不顺手引入**。

## 三、⭐ 三个由调查得出、不是由喜好得出的决定

### 3.1 ⭐ 外壳里**不能有任何数字**

E2E 里有两条**整页**断言：

| 断言 | 位置 |
|---|---|
| 危险象限下 **整页不含任何数字** | `retrospective.spec.ts:119` |
| 整页不含 `%` `正确率` `记住率` `掌握度` **`评分`** **`得分`** | `review.spec.ts:75` |
| 整页不含 `收益率` | `today.spec.ts:25` |
| 空态不含 `连续` `打卡` `完成率` `%` | `retrospective.spec.ts:184` |

**所以导航条、页脚、标题里一个数字都不能有。** 这不是洁癖——
是因为"整页无数字"本来就是红线 10 的最强形式，而**外壳是整页的一部分**。

推论：**任何界面元素都不得命名为"评分"或"得分"**，即使它显示的是过程分。

### 3.2 ⭐ 导航上**不挂数字、不挂红点**

`项目总纲` §2.1 ⑤ 对"想忘记"那个时刻的规定是：**一句陈述，无推送、无红点、无催促词**。

所以导航**只有文字**。**不给"复习 3"这种角标**——角标就是把"你欠着 3 张卡"
变成一个能看见、能攀比的数字，那是红线 11（不鼓励频繁操作 / 禁止打卡计数）。

> 队列里剩几条，由**点进去之后**的那句话回答，不由导航栏预告。

### 3.3 路由表是**唯一真源**

现在 `parseHash` 是手写 if 链、四个 `HREF` 常量散在各处、标题是 `App.tsx` 里的
嵌套三元。新增一页要改四个地方，漏一处编译器不报错。

改成一张**声明式路由表**，`parseHash` / 导航 / 标题 / `HREF` 全部从它派生。
**加一页 = 加一条表项。**

## 四、交付物

| # | 文件 | 作用 |
|---|---|---|
| 1 | `src/routing.ts` | **路由表** `ROUTES` + 由它派生的 `parseHash` / `useRoute` / `HREF` / 标题 |
| 2 | `src/ui.tsx` | `AppShell`（含导航）· `Page` · `PageSkeleton` · `ErrorNote` · `EmptyState` |
| 3 | `src/useResource.ts` | `useResource`（取数四态）· `useSubmit`（提交态） |
| 4 | 六个页面 | 改用上面的件，**删掉重复样板** |
| 5 | 测试 | 路由表单测 · `useResource` 单测 · **导航 E2E**（每页都有、当前项高亮、点击可跳转） |

### 4.1 `useResource` 收掉什么

六个页面里**约 35 处** `setLoading` / `setError` 手写样板。统一成：

```ts
const { data, error, loading, reload } = useResource(() => getDueCards(), [])
```

**顺带修掉 6 个 `set-state-in-effect` lint 警告**——因为 setState 发生在异步回调里，
而不是 effect 体内同步调用。

### 4.2 刻意**不做**的

| 不做 | 为什么 |
|---|---|
| 跨页缓存失效总线 | **没有跨页写**（今日页枢纽是下一片）。`reload()` 够用。**不为假想需求建抽象** |
| `shadcn/ui` | 宪法 §3.0 的"已采纳、未落地"要**如实标出**，不是顺手引入 |
| TanStack Router / Query | 不在锁定表，需批准；主人选了不引入 |
| 移动端 / 响应式重排 | 桌面壳，单列 |
| 主题 / 暗色模式 | 产品视觉是**刻意朴素**的（"金融软件不做动画"），加主题是反方向的改动 |

- [ ] **AC-6** 未知 hash 仍落 `unknown` 且**说自己在哪**（既有行为，不得回归）

- [ ] **AC-8** 既有 **65 单测 + 28 E2E 全绿**（不回归）
- [ ] **AC-9** 门禁 **10/10 + 退出码 0**
- [ ] **AC-10** 变异：外壳里加一个数字 / 加一个红点 / 去掉导航 → 各自变红
- [ ] **AC-11** 诚实：`shadcn/ui` 与 TanStack 的状态在宪法 §3.0 **如实标注**
