- **依据**：`AlphaCouncil-产品定义-v3.md` §六（首屏四块线框）· P0 定义「每天打开能看到动态」

## 背景与目标

P0 = D1 · D3 · I1 · T1 · J1，前四块已完成，**只剩 T1**。P0 验收句「每天打开能看到动态」里"每天打开"四个字，落点就是首屏：产品定义 §六规定**打开程序默认落在今日**，从上到下四块 —— ①需要你处理的 ②我关注的 ③今天的数据变化 ④你在重复自己。

四块里**当前只有 ② 完全可做**（D1+D3 已通）；① 可诚实做一部分（失效条件到期）；③④ 依赖未建的数据层（D4/D5 财务公告、J4 重复检测）。本切片按标的页"「还没有的部分」明说"的既有先例：**能做的做真，做不了的明说，绝不渲染成空的假区块**。

## 功能需求

| 编号 | 需求 |
|---|---|
| FR-1 | `#/` 默认落在**今日页**；关注池移到 `#/pool`；标的页路由与"未知哈希报错"行为不变（产品定义 §六：打开默认落在今日） |
| FR-2 | 后端 `GET /api/v1/today`：`{generated_at, attention}`。`attention` = **所有决策**（不限 recent 窗口）里 `as_of` 已到的失效条件，逐条展平；每条带决策 id、标的 `(market, code)`、display、action、谓词四要素 |
| FR-3 | 领域规则落在 `KillCriterion` 上：**今天 ≥ as_of 即到期**（"截至某日"的条件，当天就该看）。纯函数、日期注入、全覆盖测试 |
| FR-4 | ① 区块每条可点回标的页（携带 `market/code`），文案是**事实**：「你写的失效条件观察期已到，去核实」—— **禁止**出现"已触发 / 该卖出 / 建议关注"（系统没有指标数据源，触发与否属**未验证**，红线 1/15 + 数据四态：不把 unavailable 冒充结论） |
| FR-5 | ② 「我关注的」= 既有 `listWatchlist` + `getWatchlistQuotes` 两个请求；行情单元格从 PoolPage **提为共享组件**（先复用，不复制第二份） |
| FR-6 | ③ ④ 渲染为**一句"还没有"的事实陈述**（说明缺什么、对应哪个编号），不是空区块、不是骨架屏 |
| FR-7 | 三个请求各自失败各自说：attention 失败只影响 ①，行情失败只影响 ② 的价格列，列表本身永不因此空白（延续记录/报价分离） |
| FR-8 | 页头显示今天的日期（读者本地时区，注入时钟可测） |

## 验收标准

| 编号 | 标准 |
|---|---|
| AC-1 | `#/` → today；`#/pool` → pool；标的路由不变；未知哈希仍报 unknown；两个 HREF 常量与 parseHash 往返一致（测试改写并覆盖） |
| AC-2 | 空库 → `attention == []`、`generated_at` 带 `Z` |
| AC-3 | as_of 昨天 → 出现；as_of 明天 → 不出现（API 级） |
| AC-4 | **as_of == today → 到期**（领域级，注入日期测边界） |
| AC-5 | 一条决策多条谓词混合到期 → 只展平到期的那些 |
| AC-6 | 到期条件不漏旧决策（仓储层无 LIMIT 的全量查询） |
| AC-7 | 门禁全绿：后端 ruff/mypy/pytest + 前端四道 + 静态检查 12/12 + `dev.py check` |
| AC-8 | 变异检查 ≥ 3 条，记录于变更日志 |

## 已知的失败（本 spec 防的事故）

| # | 事故 | 防线 |
|---|---|---|
| 1 | 「观察期已到」被写成「条件已触发」—— 用未验证的结论冒充事实 | FR-4 文案硬约束；线框图里的「条件已触发」列**不做**（需 D4 财务数据） |
| 2 | 默认页改动让 `#/` 语义漂移、旧链接指向错页 | FR-1 + AC-1：测试先改写，HREF 常量全仓核对 |
| 3 | 今日页复制第二份行情单元格实现 | FR-5：QuoteCell 提为共享组件，PoolPage 改为引用 |
| 4 | attention 走 `recent(limit=50)` → 旧决策的到期条件被静默漏掉 | AC-6：全量查询，无 LIMIT（个人级规模，几千行可承受） |
| 5 | ③④ 渲染成骨架屏/空白，看起来像坏了 | FR-6：明说"还没有"的一句事实 |
| 6 | 自动跳转或红点催促用户「去处理」 | 不做：这是"拦截不是催促"——条目安静地列出，链到标的页，不弹窗不闪烁（红线 11/14） |

## 边界（本 spec 不做）

- 复盘到期提醒（「买入满 90 天该复盘」）—— 需 `decision_review_state` 表（J3 范围）
- ③ 公告与数据变化 —— D4/D5 财务公告源未接入
- ④ 重复检测 —— J4 判定算法未定义（SuperMemo 纠偏后需先定义"同一句话"）
- 市场温度 —— D6 指标未定义
- 离线数据新鲜度徽标（「数据截至 09-25」）—— 依赖磁盘缓存层（S1 还差项）
- 提醒收口到 3 个区域的完整规则（T1 完整版，随 J3/J4 落地）
