## 二、⭐ 界线（写下来，否则下一个人会滑）

## 六、门禁与变异

- [x] `dev.py check` **10/10 + 退出码 0**
- [x] 变异 6 个 —— **第一轮 4/6，两个都不是好消息**
  - ⭐ **M2「加等你」漏网（真实测试缺口）**：我把那句从陈述改成祈使
    （`到期要看的` → `等你处理`），**套件全绿**。因为禁用词**清单永远不可能穷举** ——
    没人会在写清单时想到「等你」。
    **修法：那句话改为逐字比对**（它是产品政策，和危险象限那句一样），
    清单降级为**记录每个词为什么被禁**的文档，不再是承重的那面墙。
  - ⭐ **M6 假阳性（harness 错）**：我把 `-q` 拼进了 node 参数，
    pytest 根本没跑，输出是 `file or directory not found`，
    非零退出码却被记成「抓到了」。**没跑起来的命令不算抓到** ——
    和 022 的 webServer 占用同一个错，换了身衣服。
    已加护栏：输出含「没收集到任何东西」一律判 HARNESS ERROR。
  - M5 队列名当路径：**变异编译不过 → 拒绝评分**（022 的教训按预期生效）
  - M1 / M3 / M4 全部被对的那条 E2E 抓住，恢复哈希一致
