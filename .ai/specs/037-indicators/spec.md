# spec 037 —— 技术指标：纯计算、每个口径写下来、预热段一律为空

> 状态：**已实现**（计算层）· 2026-09-29
> 相关：spec 034（K线）· TSP `backend/app/indicators/pipeline.py`
> 归属：**数据展示层** —— 那一页现在只有 K 线，没有任何「这只票在做什么」的描述

---

## 一、为什么先做这个，而不是分钟 K

分钟 K 剩下的是接线，但它卡在一个**我没定位到的根因**上（真实请求返回 `no_data`，
而传输与解析单独验证都通过）。⭐ 在同一天硬推同一条线，倾向于把「没查清」
变成「不想再查」。

指标是**纯函数**：零新数据源、零网络、零未知。`daily` 已有 214 根，
MA/MACD/RSI/KDJ 全是确定性算术。

## 二、⭐ 每个分叉都写下来，而不是继承

「标准」正是分歧所在，而分歧处每一个都会改变数字：

| 指标 | 分叉 | 本篇的选择 |
|---|---|---|
| **EMA** | 递归（`adjust=False`）vs pandas 默认 `adjust=True` | ⭐ **递归**。TSP 在 `pipeline.py` 里写了 14 次 `adjust=False` —— 而 pandas 默认是 `adjust=True`，**两者从第一根起就不同** |
| **RSI** | Wilder 平滑（`alpha=1/n`）vs 增减简单平均 | ⭐ **Wilder**。同名不同指标 |
| **KDJ** | RSV 分母是窗口高低差，**每根都在变** | ⭐ 平坦窗口时**输出 `None`** 而不是除零 |
| **ATR** | 真波幅需要**前收**，所以第一根不存在 | ⭐ 第一根 `None` |
| **布林** | 中轨是 SMA 还是 EMA | ⭐ **SMA** |
| **年化波动** | `sqrt(252)` 里的 252 | ⭐ **命名常量**。250/240 也在流通，差 1% 而没人会察觉 |

## 三、⭐ 预热段一律 `None`，这是红线 6

宪法红线 6 要求未成熟结果渲染成**空**，`S-08` 在界面层强制它。
⭐ 那条规则一路伸到这里：20 日均线在 5 根 K 线上没有值，而两个诱人的替代**都是谎**。

* `0` 说的是「均价是零」。
* **把部分均值往后带更糟** —— 它看起来像个真数，而图会把它画出来。
  ⭐ 用 5 根 K 线算出的 `MA20` 是一条穿过当下的线，读者会信它。

所以类型携带这个缺失：`float | None`，**由 API 层去渲染空白**。

有一条测试专门守这个：⭐ **`0.0` 不得出现在任何预热段** ——
因为零是一个「看起来合理」的值（价格均值为零虽然错，但不那么明显）。

## 四、⭐ 我的测试写错过一次，而代码是对的

`test_a_constant_rate_series_reproduces_its_own_daily_vol` 用**恒定** 1% 日收益率
去断言 `0.01 * sqrt(252)`。代码返回 `0.0`，⭐ **而代码是对的**：
波动率度量的是收益率的**变化**，恒定收益率没有变化。

⭐ **一个不断言「这个数字是否名副其实」的测试，就会让一个错误的期望活过评审。**

改成构造一个标准差**按定义**已知的序列（收益交替 ±0.01），闭式才成立。
并且**恒定收益率零波动那条单独留成了测试** —— 「涨得一模一样」与
「忽涨忽跌但平均一样」是两件事，而只有后者有波动。

## 五、⭐ 断言 EMA 与 RMA 必须不同

`period = 4` 时两者 alpha 分别是 0.4 与 0.25，过预热后必然分叉。

⭐ **一条「EMA 在某个输入下等于某个数」的测试，两种平滑都过。**
只断言「同一个输入下 `ema != rma`」，才能抓住「两个函数悄悄用了同一套平滑」。

## 六、验证

* **34 条测试**（含 7 条参数化的预热长度断言）
* ⭐ **真实数据实测**：茅台 321 根日线
  MA20 1275.46 · EMA20 1267.71 · MACD DIF −15.94 / DEA −11.78 / 柱 −4.16 ·
  RSI14 34.31 · 布林 1222.39 / 1275.46 / 1328.54（带宽 8.32%）· ATR14 19.10（占价 1.5%）· 年化波动 13.04%
* ⭐ **预热段全为 `None`** · **所有序列长度 == 输入长度**（长度不等会让后面每一根都错位）
* 后端 unit **999 → 1034** · ruff 0 · mypy --strict 0（100 文件）

## 七、明确不做

- **不做**指标进数据库 —— ⭐ 它们是**从 bars 派生的**，缓存下来就多了一个会过期的东西
- **不做**把指标挂到 API / 界面 —— 那是下一件，而**先把口径定死**比先接线更重要
- **不做**「均线多头 / 金叉」这类**形态判定** —— 那是策略语言，且逼近红线 1
