# AlphaCouncil · 前端

这是 AlphaCouncil 的界面层。**当前实现了 17 项功能中的五项**：D1（关注池）、
D3（行情）、I1（标的页）、T1（今日页，最小切片）、J1（决策登记），外加 J3 的
止损对质那一片。其余界面尚不存在 —— 这份 README 描述的是这几片，不是整个产品。

## 为什么前端不只是「把 API 画出来」

产品的机制要落在界面上，否则它就是一个普通的 CRUD 表单。这一片里有四处是刻意的：

| 位置 | 行为 | 为什么 |
|---|---|---|
| 提交按钮 | 理由为空时 `disabled`，并提示「这是唯一不能跳过的一步」 | 关注理由是知识层的第一条锚点，不能是可选字段 |
| 移除操作 | 成功文案是「记录没有被删除 —— 只是追加了一条「不再关注」」 | append-only 是产品承诺，界面必须说人话，不能让人以为数据没了 |
| 加载失败 | 显示「后端未启动时会出现这一行 —— 它不会静默显示成「空」」 | 空池子和拉取失败是两件完全不同的事，不能长得一样 |
| 页脚 | 「它不显示收益率，也不给你推荐」 | 红线 9 / 红线 1 的界面级落地 |
| 行情列（spec 004） | 列表与行情是**两个请求**；行情挂了只在列表下方说一句，池子照常显示 | 你写的理由是本地数据，不会失败；价格过网络，经常失败。合并会让数据源故障扣住用户自己的话 |
| 行情列（spec 004） | **不自动刷新**，只有「刷新行情」按钮 | 会自动刷新的价格把「记录页」变成「盯盘终端」（红线 11）—— 与标的页同一条纪律 |
| 行情列（spec 004） | 每行自己的四态：`无报价`（淡）/ `取数失败`（警）/ `无法确认`（警）；`ok` 但来自缓存则带「旧」标记 | 批次没有自己的状态 —— 十行说十个真话；文案由 `quoteSummary.ts`（纯函数）决定，页面只负责渲染 |

标的页（`src/InstrumentPage.tsx`）同理，四处是刻意的：

| 位置 | 行为 | 为什么 |
|---|---|---|
| 报价面板 | **不自动刷新**，只有一个「重新读取」按钮 | 会自动刷新的价格把「记录」变成「终端」，而红线 11 禁止任何推动用户更频繁操作的设计 |
| 四种数据状态 | `no_data` / `error` / `unavailable` 各有一句话，不合并 | 「来源说没有」和「来源都拒绝了我」是两件事，只有一件值得重试 |
| 陈旧价格 | 显示**并**标注「这个价格是旧的」 | 把昨天的价当今天的报，是一种安静的谎 |
| 事件时间线 | 按**写入顺序**（最早在上）排列 | 倒过来排就只剩四行互不相干的事件；顺着读才是「加入 → 改口 → 离开 → 再来」的过程 |
| 「还没有的部分」 | 明说哪几项还没建（当前是 K1–K4 / D2 / J3 剩余 / J4 / J5） | 一块看起来像加载失败的空白，会让人以为是 bug 而不是缺口。**这份清单是活的** —— 它第一版说"决策登记还没有"，J1 落地当天就作废了 |

## 决策登记（`DecisionForm.tsx` + `DecisionSection.tsx`）

这是产品里唯一一个**写下的东西将来改不了**的界面，所以它有四处不是普通表单：

| 位置 | 行为 | 为什么 |
|---|---|---|
| 失效条件 | **四段结构化编辑器**（指标 / 关系 / 阈值 / 截至日），**不是文本框** | ADR-0017 #5：一句话没人能计算，也就永远不会来找你。四段比一句话麻烦，**这份麻烦就是功能** |
| 三个必填字段 | 任一未填 → 提交按钮 `disabled`，并列出**还差哪几项** | 缺了反面证据的决策，事后会被记忆补全成它从来不是的样子 |
| 校验边界 | 前端只查**填没填**，不查**格式对不对** | 「`gross_margin` 是不是合法的指标名」是领域层的问题。在前端再写一遍这条规则，就是第二次和它意见不一致的机会 —— 所以畸形 token 送到服务端，把它自己的那句话显示出来 |
| 决策时间戳 | 每条都显示服务端盖的毫秒时间戳 | 它不是元数据，它是证据：「我是在结果出来之前这么想的」只有这一个凭据 |

## 止损对质（`StopLossPrompt.tsx` + `recovery.ts`）

「想死扛」那一刻的界面。**红线 12 的落地，也是静态检查 S-09 唯一监视的那个组件**
（`backend/checks/rules/time_cost_in_stop_loss.py` —— 它按**文件名**识别止损组件，
文件里必须出现 `恢复所需年数` 之类的字样，否则构建变红）。

| 位置 | 行为 | 为什么 |
|---|---|---|
| 主行 | **恢复所需年数：约 X.X 年（按年化 Y% 计）** | 「亏了 32%」是挂在持仓上的数字，「约 2.8 年回本」是挂在生活上的数字。只有后者会改变一个人的行为 |
| 年化率 | 是**屏幕上的输入框**，不是常量 | 藏起假设的估算是在假装自己是事实；看不见利率的读者无法判断自己有没有被安慰 |
| 五档对照表 | 10/30/50/70/90%，**并插入读者自己那一行** | 孤立的一个数字说「这就是我的处境」；一列数字说「而且再往下会变成什么样」 |
| 失效条件回读 | 原样列出**他自己写的**谓词 | 对质只有在读者认出那些字是自己的时才成立 |
| 措辞 | **不问「要不要卖」，不给任何建议** | 产品的职责是让代价可见，不是替他决定 |
| `recovery.ts` | 复利而非除法 | `0.5 / 0.15 = 3.3 年` 是错的，复利给 4.96 年。朴素除法在**每一个规模上都低估**，而这个面板的全部职责就是不低估它 |


## 设计 token

`src/index.css` 里的 `@theme` 是唯一的颜色来源（机构研报风）：

```
paper #FBFAF8 · ink #0E1A26 · navy #1E3A5F · brass #9A7B4F
rule（0.5px 分隔线）· up #C0392B（涨）· down #1E7A46（跌）· warn
```

八条可检查的界面规则（衬线只用于标题 · 数字一律 `tabular-nums` · 涨跌色+符号双编码 ·
0.5px hairline 代替阴影 · 分类用左侧 2px 竖线而非圆角胶囊 · 信息密度优先 ·
颜色只承载意义 · 空状态是一句事实陈述）都落在这一个文件里，改样式先改它。

## 跑起来

```bash
npm install
npm run dev        # http://127.0.0.1:5173
```

需要后端在 `:8000` 上（见仓库根 README）。`/api` 由 Vite 代理到后端，
配置在 `vite.config.ts`。

> ⚠️ `vite.config.ts` 里显式写了 `server.host: '127.0.0.1'`。
> Vite 默认绑的是 `localhost`，在 Node 18+ 上会解析成 IPv6 的 `::1`，
> 于是任何走 `127.0.0.1` 的请求（包括它自己的代理）都会看到「端口没开」。
> **不要删掉这一行。**

## 路由

三条，用 hash 写在 URL 里（不需要静态托管配 rewrite 规则）：

| 地址 | 页面 |
|---|---|
| `#/` | 今日页（默认 —— 打开程序落在这里） |
| `#/pool` | 关注池 |
| `#/i/{market}/{code}`，如 `#/i/sh/600519` | 标的页 |

**这是过渡方案，代码里也这么标注了。** 前端规格点名的是 TanStack Router 与
TanStack Query，两者属于同一次改动 —— 把「手写取数 + 手写导航」一起换成数据层，
而不是分两次各换一半。二十行手写路由坦白地是临时的；装了一半的路由器不是。

认不出的地址会显示「这个地址看不懂」，**不会**静默回退到今日页 —— 为一个打错的
链接显示一个看起来合理的页面，正是那种「像成功的失败」。

## 今日页（`TodayPage.tsx`，spec 005）

P0 的最后一块。产品定义 §六的首屏四块里，当前**能做的一块半**是真的，其余明说：

| 区块 | 状态 | 说明 |
|---|---|---|
| ① 需要你处理的 | ✅ 一部分 | 到期的失效条件（`GET /api/v1/today` 全量扫描决策）。文案硬规则：**「观察期已到，去核实」**，绝不说「已触发」—— 系统没有指标数据源，触发与否未验证 |
| ② 我关注的 | ✅ | 关注池 + 行情列，复用 `QuoteCell`；与 ① 是三个独立请求，各自失败各自说 |
| ③ 今天的数据变化 | 🚫 明说没有 | 公告/财务源未接入（D4/D5） |
| ④ 你在重复自己 | 🚫 明说没有 | J4 判定算法未定义 |

区块 ① 有意**安静**：条目列在那里、链到标的页，不弹窗、不闪红点 ——
这是"拦截不是催促"（红线 11/14）。

## 检查（四道门禁）

前端已经接进两处门禁，**两处的步骤清单必须保持一致**：

| 位置 | 命令 |
|---|---|
| 仓库根 | `python backend/scripts/dev.py check`（含四个 `frontend-*` 门禁） |
| CI | `.github/workflows/ci.yml` 的 `frontend` job |

```bash
npm run typecheck  # tsc -b（三份 tsconfig：app / node / test）
npm run lint       # oxlint
npm test           # vitest run
npm run build      # tsc -b && vite build
```

**本地门禁必须和 CI 跑同一组东西。** 2026-09-26 之前 `dev.py check` 里
**一个前端门禁都没有**，而 CI 早在跑前端 —— 于是本地全绿对前端一无所知。
这与 CI 那个 `frontend` job 要修的是同一个缺陷，只是低了一层。

`tsconfig.test.json` 单独存在，是为了让 `node` 类型只出现在测试里。
把它加进 `tsconfig.app.json` 会让 `process` / `require` 在浏览器代码里
通过类型检查、然后运行时炸掉。

## 测试覆盖了什么

**51 个测试，全部是纯逻辑**：路由解析、格式化、以及恢复年数的算术。

三条值得单独说：

1. `format.test.ts` 会**读 `index.css` 的原文**，断言 `--color-up` 是红、
   `--color-down` 是绿。涨红跌绿是 A 股惯例、也是本项目唯一**与美国默认相反**的
   约定 —— 因此最容易被好心人「顺手改回来」。色值映射活在 CSS 里，
   没有别的东西够得着它。
2. `recovery.test.ts` 断言**复利结果大于朴素除法**，而不是只断言复利结果本身。
   后者只证明算得对，前者证明它**没有退化成那个错误的算法** —— 那才是它存在的理由。
3. `recovery.test.ts` 还断言 `formatYears(NaN)` 是 `—` 而不是 `永远`。
   输入框空着会产生 `NaN`，把它渲染成「永远」是在陈述一件没人算过的事实 ——
   正是本项目处处当作缺陷的那类**自信的错误答案**。

⚠️ **没有覆盖的**：React 组件的渲染与交互。那需要 Playwright（见下）。

⚠️ **2026-09-26 的一次人工浏览器验证**（本机 Edge + `playwright-core`，打真实 uvicorn）
逐项确认了四个区块标题、决策与谓词渲染、止损面板的三个数字、谓词编辑器是结构化字段、
空表单时按钮禁用 —— **并因此抓到一个任何测试都抓不到的间歇性 500**
（`.ai/regressions/0003`）。**但那次验证用的探针脚本已经删掉，所以它不会自动再跑。**
这是当前最值得补的缺口。

## 已知与规格的差距

- lint 用的是 `oxlint`，前端规格要求 **Biome**
- 组件是手写的，规格要求 **shadcn/ui**
- 数据获取还是手写 `useEffect`，规格要求 **TanStack Query**
- 路由是手写 hash 路由，规格要求 **TanStack Router**
- 组件测试（Playwright）**还没有** —— 当前只有纯逻辑的单测，且**不进仓库**
- 涨跌之外的时间格式依赖浏览器本地时区，没有固定时区的测试

`src/App.tsx` 与 `src/InstrumentPage.tsx` 里那三条**刻意保留**的 lint 警告
（`set-state-in-effect`）就是上面第 3 条的症状。它们指向的是正确但更远的答案 ——
TanStack Query —— 而不是 bug：在 effect 里发请求正是这个规则存在的那个合法场景。
留着是因为，把它静音就等于把「数据层该换了」这个信号也一起藏掉了。
